## Описание

Учебный проект "веб-мессенджер".
«[Ссылка на макет Figma](https://www.figma.com/design/c2R5HiXAYJUdBvQzPWNVdH/messenger-prototype?node-id=0-1&p=f&t=QbbBVD4rVzjUKcGf-0)»

На данном этапе прототип приложения представляет собой MPA.
«[Ссылка на приложение](https://vitklassen-messenger.netlify.app/)»

## Установка

- `npm install` — установка стабильной версии,
- `npm run dev` — запуск версии для разработчика,
- `npm run start` — сборка стабильной версии.
